# MIY.MID Studio

AI動画の「演出」を設計するためのシンプルなツールです。

## Concept

「生成AIに何を作らせるか」ではなく、**どう演出させるか**を設計する。

## Core

- 静止画 + 静止画 → 動画演出
- 初め / 中盤 / 終盤
- 複数エフェクト
- 覚醒 / 爆発 / 神秘 / 高速などの演出プリセット
- エフェクト量 / 速度 / 方向
- 英語プロンプト生成
- スマホ優先UI

## Run

`index.html` をブラウザで開くだけで動作します。

## Positioning

MIY.MID Studioは画像生成ツールではなく、AI動画に対して「どう魅せるか」を指示するための演出設計ツールです。
